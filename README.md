## 免备案云服务器，免的到底是什么

免备案免的是中国大陆的 ICP 备案流程。服务器在境内，对外提供公开访问就必须备案；服务器放在香港、新加坡、美国、德国等境外节点，则不受这个流程约束，业务部署完即可上线。这也是“免备案”和“境外服务器”在实操中几乎是同义词的原因。

但要留意一个容易混淆的口径：市面上还有一类“国内免备案虚拟主机”，做法是机房在国内、靠 CDN 映射技术绕开备案，价格便宜（年付几十到几百元），但本质上是虚拟主机，给不了完整的 VPS 控制权。如果你要跑 Docker、编译、自建服务，这类产品不合适，应该看真正的海外 VPS。
